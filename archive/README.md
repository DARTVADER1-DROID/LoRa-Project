# Archive — Legacy Project Snapshot

This directory preserves the repository's earlier implementation and documentation for traceability and reference.

## Contents

- `firmware/` — previous campus-assistance and messaging Arduino sketches.
- `messaging-app/` — previous Rust/Tauri desktop serial application.
- `docs/` — previous general implementation, messaging, reliability, hardware and validation documents.
- `tests/` — previous host-side reliability and source-contract tests.
- `ci/arduino-build.yml` — previous GitHub Actions Arduino build workflow.

## Status

Everything in this directory is **archived and inactive**. It is not the current implementation baseline and must not be used as evidence that the newly agreed Campus Assistance requirements are implemented.

The Git history also remains intact. Archiving changes the active repository layout; it does not rewrite or erase prior commits.

The authoritative current target specification is in [../docs/campus-assistance/](../docs/campus-assistance/README.md).
